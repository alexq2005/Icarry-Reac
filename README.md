# iCarry (React + Vite)

Tienda SPA de artículos de Dota 2 hecha con React, Vite y React Router. El catálogo se consulta desde Firestore y el carrito se gestiona con Context API.

## Cómo correrlo

```bash
npm install
npm run dev
```

Para cargar imágenes desde `/admin`, configurá `VITE_IMGBB_API_KEY` en `.env.local`. En Vercel, agregá la misma variable en **Project Settings → Environment Variables** antes de desplegar.
